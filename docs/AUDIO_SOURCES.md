# Sumber audio

Panel musik berisi pilihan rekaman yang dinyanyikan Budi Doremi, termasuk cover
dan penampilan live. Pemilik proyek mengonfirmasi izin penggunaan audio pada
3 November 2026. Daftar berikut mencatat sumber setiap file tambahan.

Empat rekaman awal (`tolong`, `tak-kan-hilang`, `mesin-waktu`, `melukis-senja`)
berasal dari file MP3 yang sebelumnya disediakan pengguna di Downloads.

Rekaman tambahan diambil dari YouTube melalui CnvMP3. Nama file lokal mengikuti
kolom pertama, dengan ekstensi `.mp3`.
